# Declarative integration template

Files a capture as an issue in your tool, with no code: requests and their mappings live in `manifest.json`.

Press **Use this template** to make your own repository.

**Docs:** the calls it answers, their inputs and outputs, and the security rules: https://1weavr.com/docs/integration-templates#declarative

Security reports: security@1weavr.com (see `SECURITY.md`). Licence: MIT (see `LICENSE`).
